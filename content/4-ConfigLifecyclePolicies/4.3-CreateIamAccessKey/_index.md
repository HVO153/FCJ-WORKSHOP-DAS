### Create Access Key

You have already created an IAM User in the previous steps.  
In this section, you will create an access key to authenticate when sending data from your project.

1. Go to [IAM](https://us-east-1.console.aws.amazon.com/iam/home)  
     + Select the IAM User you created.  
     + Click **Create access key**.

![acckey](/images/4.LifecyclePolicies/008-acckey.png)

2. Continue:  
     + Select **Command Line Interface**.  
     + Check the confirmation box.

![acckey](/images/4.LifecyclePolicies/009-acckey.png)

3. Continue:  
     + Enter `accesskey` in the **Description tag value** field.  
     + Click **Create access key**.

![acckey](/images/4.LifecyclePolicies/010-acckey.png)

4. Continue:  
     + Click **Download .csv file**.  
     + Click **Done** to finish.

![acckey](/images/4.LifecyclePolicies/011-acckey.png)
